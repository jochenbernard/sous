# Examples

Ten recipes the chapters quote. Each is a complete, cookable version of a
classic French dish, and between them they cover every construct the format
has.

A chapter quotes a span of one of these files byte for byte. A case none of
them covers is added to one of them, and the recipe stays cookable.

| File                                                 | Covers                                                                       |
| ---------------------------------------------------- | ---------------------------------------------------------------------------- |
| [boeuf-bourguignon.sous](boeuf-bourguignon.sous)     | A braise, with a header, four steps, precise timers, and two staples.        |
| [moules-marinieres.sous](moules-marinieres.sous)     | A quick dish, with eight ingredients, an optional one, a staple, and two cookware. |
| [quiche-lorraine.sous](quiche-lorraine.sous)         | A tart, with three groups, references between them, and a full header above its body. |
| [gratin-dauphinois.sous](gratin-dauphinois.sous)     | A gratin, with a compound timer and, in its header alone, every field of the form. |
| [vinaigrette.sous](vinaigrette.sous)                 | A sauce, with a yield, no servings, and neither cookware nor timers.         |
| [bouillabaisse.sous](bouillabaisse.sous)             | A stew, with three groups where the last consumes the other two.             |
| [croque-monsieur.sous](croque-monsieur.sous)         | A sandwich, consuming an intermediate no group of the file produces.         |
| [brioche.sous](brioche.sous)                         | A dough, with a qualitative timer, a precise one in days, and two ranges.    |
| [crepes.sous](crepes.sous)                           | A batter, with a countable yield alongside a number of servings.             |
| [madeleines.sous](madeleines.sous)                   | A bake, with a countable yield, a precise timer, and a range timer.          |

The 400 g of bechamel [croque-monsieur.sous](croque-monsieur.sous) consumes is
40 g butter, 40 g flour, and 350 ml milk cooked out with nutmeg. No group of
that file produces it.
