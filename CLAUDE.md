# Sous

This repository holds the Sous language specification. Nothing built on Sous
belongs here.

## The specification stands alone

The specification defines the format and refers to no implementation of it. An
implementation may cite a chapter; a chapter cites no implementation. Never
write a rule to match what a program does, and never settle an open question by
reading one.

## Writing

`docs/writing-style.md` is the single authority on how every Markdown file here
is written; follow it for every line.

## Layout

| Path        | Contents                                                    |
| ----------- | ----------------------------------------------------------- |
| `spec/`     | The specification, one chapter per file                     |
| `examples/` | The recipes the chapters quote                              |
| `docs/`     | Guidance for writing the specification                      |
